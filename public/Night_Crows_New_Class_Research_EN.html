Companion to the Night Crows New Class Design & Development Document · Orb / Cannon / Gauntlets · Created 2026-11-17
Click a shaded cell to type or paste text or screenshots. Select a status from the dropdown. Click “+ Add Row” for more space. When finished, click “Export Completed Form” and send back the HTML file.

Use this template to collect information on Orb, Cannon, Gauntlets, and related systems. Sections match the design document. Each owner should fill in their assigned tables.

Instructions

  1. Cite every entry: Add a source link (official notice, patch notes, or timestamped video). Paste in-game screenshots into the Notes cell or comments for that row.

  2. Identify the server: Record Global and Korea separately. Enter “Global” or “Korea” in the Server column.

  3. Provide names in three languages: Enter skill, class stage, and item names in Simplified Chinese / Korean / English. Leave unknown names blank.

  4. Date format YYYY-MM-DD. Keep the original units (%, seconds, quantity, Diamonds, KRW).

  5. Flag uncertain information: Mark estimates or unverified details as “To confirm” in Notes and add them to the final question list.

  6. Add rows as needed: You may add rows or columns. Do not delete existing columns.

Useful sources:Global Patch Notes; Global Game Guide; Global Probability Guide; Korean Patch Notes. If an official page redirects to login, append ?wmsso_sign=check to the URL and try again.
